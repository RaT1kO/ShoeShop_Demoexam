# Название проекта

Магазин обуви "Название еще на обсуждении"

## Проблема

Небольшой магазин обуви планирует открыть онлайн продажи и ведение учета товаров и заказов на бумаге или в Excel не удовлетворяет эти требования.

## Пользователи

- Guest
  - Имеет возможность рассматривать каталог
- User
  - Имеет возможность просмотра и покупки товара
- Admin
  - Имеет возможность создавать, удалять и изменять карточки товаров в каталоге (полный доступ)

## Цель проекта

Создать удобный интерфейс для клиента чтобы выбирать товар и оформлять заказы онлайн, а продавцу видеть актуальные данные о наличие товара и заказах.

## Метрика успеха

- Время оформления заказа — менее 3 минут
- Время поиска товара через систему поиска/фильтрации — менее чем 5 кликов
- Обновление статуса товара после продажи в локальном времени

## Границы

- Отсутствие реальной платежной системы
- Отсутствие учета необходимости доставки
- Отсутствие аналитики и статистики действий с товарами
- Отсутствие слежки за пользователем, нет системы рекомендаций на основе поведения пользователя

## Риски

- Обновления могут вызвать ошибки в системе
  - Необходим резервный файл отката
- Долгий отклик приложения при использовании функций
  - Оптимизация кода
- Мало возможностей поиска и сортировки
  - Добавление фильтров
  - Оптимизация сортировки
